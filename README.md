# Memory Game

Memory Game — браузерная игра на развитие памяти.

Игроку нужно найти все 8 пар одинаковых карточек среди 16 карточек.

## Возможности

- 16 карточек и 8 уникальных пар;
- случайное перемешивание карточек при каждом запуске;
- анимация переворота карточек;
- подсчёт ходов;
- подсчёт найденных пар;
- задержка перед закрытием несовпавших карточек;
- автоматическое определение победы;
- модальное окно с результатом игры;
- кнопка запуска новой игры без перезагрузки страницы;
- таблица лидеров;
- сохранение результатов в `localStorage`;
- отображение 10 лучших результатов;
- сортировка результатов по количеству ходов;
- адаптивная верстка для мобильных устройств;
- поддержка клавиатурной навигации;
- закрытие модальных окон по кнопке, `Escape` и клику по фону.

## Запуск проекта

Проект не требует установки зависимостей.

Для запуска достаточно открыть файл `index.html` в браузере.

Также проект можно запустить через любой локальный статический сервер.

Например, с помощью VS Code и расширения Live Server:

1. Открыть проект в VS Code.
2. Установить расширение Live Server.
3. Нажать правой кнопкой мыши на `index.html`.
4. Выбрать **Open with Live Server**.
